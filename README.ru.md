# Paste as File для bb

[English](README.md)

Большой текст, вставленный в поле ввода bb, превращается во вложение-файл — как
в ChatGPT: над полем появляется чип вместо простыни текста, агент получает файл
вместе с сообщением.

- Срабатывает от **1500 символов или 30 строк** (настраивается).
- `.json`, если текст — JSON; `.txt` для логов; иначе `.md`. Имя — по первому
  заголовку или строке: `pasted-<slug>-ЧЧММСС.<расш>`.
- **⌘⇧V / Ctrl+Shift+V** — вставить текстом при любом размере.
- Вставки с файлами (скриншоты) обрабатывает сам bb, как раньше.
- Настройки на русском и английском: вкл/выкл и оба порога.

Вместе с [темой Pokecut](https://github.com/VKirill/bb-plugin-pokecut-theme)
вложения выглядят карточками файлов, а вставленный текст отмечен акцентной
плиткой; работает с любой темой.

```sh
bb plugin install https://github.com/VKirill/bb-plugin-paste-file
```
